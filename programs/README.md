# Loyalty programme logos

Full-colour logos for bank and hotel loyalty programmes used by the World Traveler Club Miles & Points app.
Each file is named after the programme slug in `fds_mp_programs`. SVG view boxes are trimmed to the drawn
logo so it fills its tile. `sources.json` lists where every file came from and its licence.

Logos are trademarks of their owners and are shown only to identify the programme. Files from Wikimedia Commons
are public domain unless the licence column says otherwise (CC BY-SA files need attribution).

Served by jsDelivr: `https://cdn.jsdelivr.net/gh/obey24com/icons-logos@develop/programs/<file>`
